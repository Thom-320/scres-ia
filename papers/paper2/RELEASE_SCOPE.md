# Paper 2 release scope

This is the manuscript-local release boundary. The detailed governance note is
[`docs/PAPER2_RELEASE_SCOPE.md`](../../docs/PAPER2_RELEASE_SCOPE.md); this file is the path used by
the paper's release tests and reviewer bundle.

The release includes only the retained outer-loop search claims, the declared physical panels,
Figure 5 identity, the explicitly contracted architecture comparisons, and the bounded seasonal
development sensitivity. It excludes DES validation, Simulink reproduction, organisational or
physical-chain learning, within-episode control claims, universal UCB superiority, neural-premium
wording, and all retracted figures.

Every paper-facing number must resolve to one row in `claim_lock.json`. A result outside its stated
contract, scope or evidence grade is not admitted by changing its wording.
